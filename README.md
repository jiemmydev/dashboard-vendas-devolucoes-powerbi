# dashboard-vendas-devolucoes-powerbi
## 📌 Sobre o Projeto  Dashboard executivo no **Power BI** para análise consolidada de vendas e devoluções (2020–2022).   Contempla integração de bases históricas, modelagem relacional *Star Schema* e métricas em DAX para monitorar faturamento, volume de pedidos, top SKUs e causas-raiz de devoluções por região.
